# Repository Information
- This is a graspfruit demo based on mujoco and lerobot.
- The training datasets "grasp_apple_dataset" and "graspfruit_demo" are collected by keyboard teleoperation in mujoco simulation environment.
- In this demo, two kinds of imitaion learning methods, i.e., "act" and "smolvla", are employed to train the policy for grasping fruits.
- The python package "graspfruit" comes from the repository [GraspFruit](https://github.com/Dev-EmbodiedAI/GraspFruit.git).
- The python package "mujoco_env" comes from the repository [lerobot-mujoco-tutorial](https://github.com/flyingGH/lerobot-mujoco-tutorial.git).
