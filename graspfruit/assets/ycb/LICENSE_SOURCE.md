# YCB fruit assets

The apple (`013_apple`), banana (`011_banana`), and pear (`016_pear`) meshes are derived from the YCB Object and Model Set via the `ai-habitat/ycb` mirror. That dataset is marked CC-BY-4.0. Visual meshes retain the scanned geometry/texture; collision meshes are convex hulls generated locally from the same geometry.

Source: https://huggingface.co/datasets/ai-habitat/ycb
